# ໂຄງສ້າງລະບົບ MiniPos (ຄູ່ມືອ່ານໂຄ້ດ)

ເອກະສານນີ້ອະທິບາຍວ່າແຕ່ລະໂຟນເດີ ແລະ ໄຟລ໌ເຮັດໜ້າທີ່ຫຍັງ ເພື່ອໃຫ້ຊອກ ແລະ ແກ້ໄຂໂຄ້ດໄດ້ງ່າຍໃນອະນາຄົດ.

## ຫຼັກການຂອງໂຄງສ້າງ

- **ແຕ່ລະໄຟລ໌ບໍ່ເກີນ 500 ແຖວ.** ໄຟລ໌ໃຫຍ່ຖືກແຍກເປັນໄຟລ໌ຍ່ອຍ ແລ້ວດຶງເຂົ້າມາໃຊ້ດ້ວຍ `require` ຢູ່ຈຸດເດີມ.
- **ທຸກໄຟລ໌ຍ່ອຍມີຄຳອະທິບາຍພາສາລາວຢູ່ເທິງສຸດ** ວ່າເຮັດໜ້າທີ່ຫຍັງ ແລະ ຖືກແຍກມາຈາກໄຟລ໌ໃດ.
- **ໄຟລ໌ຫຼັກ (ຈຸດເຂົ້າ) ມີແຜນທີ່ໄຟລ໌ຢູ່ເທິງສຸດ** — ລາຍຊື່ໄຟລ໌ຍ່ອຍທັງໝົດທີ່ມັນດຶງມາໃຊ້ ຕາມລຳດັບ.
- **URL ທຸກໜ້າຄືເກົ່າ.** ການແຍກໄຟລ໌ບໍ່ໄດ້ປ່ຽນລິ້ງ, ເມນູ ຫຼື ທີ່ຢູ່ AJAX ໃດໆ.
- **ໄຟລ໌ຍ່ອຍໃຊ້ຕົວແປຮ່ວມກັບໄຟລ໌ຫຼັກ** (ເພາະ `require` ແລ່ນໃນ scope ດຽວກັນ) — ຕົວແປທີ່ກຳນົດກ່ອນ `require` ໃຊ້ໄດ້ໃນໄຟລ໌ຍ່ອຍເລີຍ.
- **ລຳດັບການ `require` ສຳຄັນ** — ຫ້າມສະຫຼັບ, ເພາະບາງສ່ວນໃຊ້ຕົວແປ ຫຼື ຟັງຊັນທີ່ສ່ວນກ່ອນໜ້າສ້າງໄວ້.
- **ໂຟນເດີທີ່ມີແຕ່ໄຟລ໌ຍ່ອຍ ມີ `.htaccess` ທີ່ `Require all denied`** — ເປີດໄຟລ໌ຍ່ອຍຜ່ານ browser ໂດຍກົງບໍ່ໄດ້ (403), ໃຊ້ໄດ້ສະເພາະຜ່ານ `require`.

## ການເຮັດວຽກຂອງ 1 request

```
browser → pages/<ໂມດູນ>/<ໜ້າ>.php
            ├─ require config/db.php          (ເຊື່ອມ DB, session, ກວດສິດ, ຟັງຊັນຊ່ວຍ)
            ├─ require api/<ໂມດູນ>_backend.php (ຮັບ POST/AJAX + ກຽມຂໍ້ມູນ) — ບາງໜ້າ
            ├─ require layouts/header.php      (<html><head> + CSS/JS ພື້ນຖານ)
            ├─ ... HTML ຂອງໜ້າ (ແຍກເປັນ partials/)
            └─ require layouts/footer.php
```

ທຸກໜ້າໃນ `pages/` ຖືກໂຫຼດຢູ່ໃນ iframe ຂອງ `home/dashboard.php` (ໂຄງຫຼັກ: ແຖບເທິງ + ເມນູຂ້າງ).

## ໂຟນເດີຫຼັກ

| ໂຟນເດີ | ໜ້າທີ່ |
|---|---|
| `config/` | ການຕັ້ງຄ່າ ແລະ ຈຸດເລີ່ມຕົ້ນຂອງທຸກ request (`db.php`) |
| `config/bootstrap/` | ເຊື່ອມຕໍ່ DB, session + ສິດ, ສະຫຼັບສາຂາ |
| `config/migrations/` | ອັບເດດໂຄງສ້າງ DB ອັດຕະໂນມັດ (ແລ່ນຄັ້ງດຽວຕໍ່ເວີຊັນ `.db_schema_vN`) |
| `config/helpers/` | ຟັງຊັນຊ່ວຍທົ່ວລະບົບ: ເງິນ/ການຕັ້ງຄ່າ, ສິດ, ທະນາຄານ, ສາຂາ, ແຈ້ງເຕືອນ, ໝົດອາຍຸ |
| `api/` | Backend ຂອງແຕ່ລະໂມດູນ (controller + AJAX) |
| `api/pos/` | ສ່ວນຍ່ອຍຂອງ `pos_backend.php`: checkout, ພິມ LAN, ເພີ່ມລູກຄ້າ, ໂປຣໂມຊັ່ນ, ຂໍ້ມູນໜ້າຂາຍ |
| `auth/` | ເຂົ້າ/ອອກລະບົບ ແລະ ກວດລະຫັດຜ່ານ |
| `home/` | `dashboard.php` (ໂຄງຫຼັກ) ແລະ `home.php` (ໜ້າພາບລວມ) |
| `home/partials/` | ສ່ວນຍ່ອຍຂອງ dashboard (navbar, JS ແຈ້ງເຕືອນ, ສີທີມ...) ແລະ home (ຂໍ້ມູນ, ກຣາຟ) |
| `layouts/` | header, footer, sidebar, ແມ່ແບບໃບບິນ |
| `pages/` | ທຸກໜ້າຂອງລະບົບ, ແຍກຕາມໂມດູນ |
| `lang/<lo,en,th,zh>/` | ຂໍ້ຄວາມແປ 4 ພາສາ (ເອີ້ນໃຊ້ດ້ວຍ `t('key', 'ຄ່າເລີ່ມຕົ້ນພາສາລາວ')`) |
| `themes/` | CSS ຂອງແຕ່ລະໜ້າ (`themes/pos/` = CSS ໜ້າຂາຍ ແຍກ 3 ໄຟລ໌) |
| `assets/` | ຮູບ, ຟອນ, JS ແລະ CSS ທົ່ວລະບົບ (`assets/css/global-custom/`, `assets/css/pages/menu-sidebar/`) |
| `plugins/`, `dist/`, `bootstrap/`, `sweetalert/`, `vendors/` | ຫ້ອງສະໝຸດພາຍນອກ — ບໍ່ແກ້ໄຂ |
| `backups/` | ໄຟລ໌ສຳຮອງຖານຂໍ້ມູນ ແລະ ສຳເນົາໂຄ້ດ |

## ໂມດູນທີ່ຖືກແຍກໄຟລ໌

### ໜ້າຂາຍ (POS)
- `pages/pos/pos.php` — ໜ້າຂາຍ
- `pages/pos/partials/js/pos_checkout_js.php` → `checkout/` (ສະກຸນເງິນ, ວິທີຊຳລະ, ສົ່ງການຂາຍ, ໃບບິນ, ບິນຄົວ, ພິມ)
- `pages/pos/partials/js/pos_cart_js.php` → `cart/` (ສະແດງກະຕ່າ, ສະຕັອກ/ຈຳນວນ, ເພີ່ມສິນຄ້າ)
- `pages/pos/partials/js/pos_bills_js.php` → `bills/held_orders.php` (ບິນພັກ)
- `pages/pos/customer_display.php` → `partials/customer_display/` (ຈໍລູກຄ້າ)
- `api/pos_backend.php` → `api/pos/`

### ສິນຄ້າ
- `pages/products/products.php` → `actions/` (ເພີ່ມ, ເພີ່ມຫຼາຍລາຍການ, ແກ້ໄຂ, ລົບ) + `partials/products/` (ຕາຕະລາງ, JS)
- `pages/products/components/form_add_product.php` → `components/add_product/`

### ລາຍງານ
- `pages/reports/partials/reports_backend.php` → `partials/reports_backend/` (ລາຍລະອຽດບິນ, ລົບບິນ, ຕົວກັ່ນຕອງ, ແຖວການຂາຍ, ສະຖານະໜີ້)
- `pages/reports/partials/js/reports_js.php` → `partials/js/reports/` (ເບິ່ງບິນ, ພິມຄືນ)
- `daily_report.php`, `category_sales.php`, `financial.php` → `partials/<ຊື່ໜ້າ>/`

### ລູກຄ້າຕິດໜີ້
- `pages/customer_debts/customer_debts.php` → `partials/` (CSS, popup, JS)
- `api/customer_debts_backend.php` — AJAX: ລາຍລະອຽດ, ຮັບຊຳລະ, ເພີ່ມໜີ້ຍົກມາ, ຍົກເລີກ, ຄົ້ນຫາລູກຄ້າ
- `pages/reports/debt_report.php` — ລາຍງານໜີ້

### ນຳເຂົ້າ / ໂອນສິນຄ້າ
- `import_stock.php`, `import_list.php` → `partials/import_stock/`, `partials/import_list/`
- JS: `components/import_stock/`, `components/import_list/`, `components/transfer/`

### ການຕັ້ງຄ່າ
- `settings/stores`, `settings/loyalty`, `settings/printers`, `settings/expiry` → `partials/` ຂອງແຕ່ລະໂຟນເດີ
- `settings/print_barcode/print_barcode_js.php` → `js/print_execute.php`

## ເມື່ອຈະເພີ່ມໂຄ້ດໃໝ່

1. ຖ້າໄຟລ໌ໃກ້ຈະເກີນ 500 ແຖວ, ແຍກສ່ວນທີ່ເປັນໜ້າທີ່ດຽວກັນອອກເປັນໄຟລ໌ຍ່ອຍ ແລ້ວ `require __DIR__ . '/…'` ຢູ່ຈຸດເດີມ.
2. ໃສ່ຄຳອະທິບາຍພາສາລາວຢູ່ເທິງສຸດຂອງໄຟລ໌ໃໝ່ (ໜ້າທີ່ ແລະ ຖືກໃຊ້ຈາກໃສ).
3. ຖ້າເປັນໂຟນເດີໃໝ່ທີ່ມີແຕ່ໄຟລ໌ຍ່ອຍ, ສຳເນົາ `.htaccess` (`Require all denied`) ໃສ່ນຳ.
4. ໃນໄຟລ໌ຍ່ອຍ ໃຊ້ `__DIR__` / `dirname(__DIR__)` ສຳລັບທີ່ຢູ່ໄຟລ໌ ຢ່າໃຊ້ທີ່ຢູ່ແບບ relative.
5. ຖ້າເພີ່ມຄໍລຳ/ຕາຕະລາງ DB, ເພີ່ມໃນ `config/migrations/` ແລ້ວປ່ຽນເລກເວີຊັນ `.db_schema_vN` ໃນ `config/db.php`.
6. ຂໍ້ຄວາມທີ່ຜູ້ໃຊ້ເຫັນ ໃຊ້ `t('ໂມດູນ.key', 'ຂໍ້ຄວາມລາວ')` ແລະ ເພີ່ມຄຳແປໃນ `lang/` ທັງ 4 ພາສາ.
